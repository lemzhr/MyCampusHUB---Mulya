2. Dasar Teori
2.1 Antarmuka Pengguna (UI) dan Pengalaman Pengguna (UX)
Antarmuka pengguna (User Interface) adalah tampilan yang berinteraksi langsung dengan pengguna, sedangkan pengalaman pengguna (User Experience) adalah kesan dan kemudahan yang dirasakan pengguna saat memakai aplikasi. Antarmuka yang baik disusun konsisten, jelas, dan mudah dipahami, misalnya dengan pengelompokan menu, penggunaan ikon yang mewakili fungsinya, serta pembedaan warna antar-menu.
2.2 Indikator Progres Langkah (Stepper)
Indikator progres menunjukkan posisi pengguna dalam alur yang terdiri dari beberapa tahap, misalnya “2 dari 3”. Elemen ini membantu pengguna mengetahui berapa langkah yang sudah dan belum diselesaikan, sehingga proses pendaftaran terasa lebih terarah.
2.3 Komponen Kartu (Card)
Card adalah komponen Material Design yang mengelompokkan informasi dan aksi yang saling berkaitan dalam satu wadah. Pada halaman Unggah Dokumen, setiap dokumen (KTP, KTM, dan foto profil) ditampilkan dalam satu kartu yang memuat gambar contoh, judul, dan tombol aksi.
2.4 Pengambilan Gambar dan Pemilihan Berkas
Aplikasi dapat memperoleh gambar dari dua sumber, yaitu kamera perangkat (Ambil Foto) dan penyimpanan perangkat (Pilih File). Pada Flutter, fungsi ini umumnya dibuat dengan bantuan paket tambahan seperti image_picker dan file_picker. Aplikasi perlu meminta izin pengguna terlebih dahulu untuk mengakses kamera dan penyimpanan.
2.5 Penyimpanan Dokumen pada Cloud Storage
Dokumen yang dipilih pengguna dikirim ke layanan penyimpanan awan seperti Firebase Cloud Storage, bukan disimpan di dalam aplikasi. Pada Flutter, layanan ini diakses melalui paket firebase_storage. Keterangan “Terhubung” pada rancangan menandakan bahwa aplikasi sudah tersambung ke layanan penyimpanan tersebut. Karena KTP dan KTM termasuk data pribadi, penyimpanannya perlu dilindungi dengan aturan akses (security rules) dan autentikasi pengguna.
2.6 Menu Grid
Menu grid menampilkan beberapa pilihan fitur dalam susunan kotak yang rapi, biasanya berisi ikon dan label. Pada Flutter, tata letak ini dapat dibuat dengan widget GridView. Tampilan ini memudahkan pengguna menemukan fitur utama dalam satu layar, seperti pada beranda My Campus Hub.
2.7 Bilah Navigasi Bawah (Bottom Navigation Bar)
Bilah navigasi bawah adalah komponen untuk berpindah antar-halaman utama dengan satu sentuhan, dan mudah dijangkau ibu jari. Pada Flutter, komponen ini dibuat dengan widget BottomNavigationBar atau NavigationBar. Pada rancangan, bilah ini berisi Home, Jadwal, Kalender, dan Notifikasi.

B.3 Membuat Fungsi Login (_login)
Langkah 6: Tambahkan metode _login() async
    
1. Validasi form dengan _formKey.currentState!.validate()
    
2. Set _isLoading = true
    
3. Panggil FirebaseAuth.instance.signInWithEmailAndPassword() dengan email dan password
    
4. Simpan status login ke SharedPreferences: prefs.setBool('isLoggedIn', true)
    
5. Navigasi ke HomeScreen menggunakan Navigator.pushReplacement()
    
6. Tangani error FirebaseAuthException: tampilkan pesan sesuai error code
      
(user-not-found, wrong-password, invalid-email)
    
7. Set _isLoading = false di blok finally
B.4 Membuat Fungsi Registrasi (_register)
Langkah 7: Tambahkan metode _register() async
    
1. Validasi form
    
2. Panggil FirebaseAuth.instance.createUserWithEmailAndPassword()
    
3. Simpan data user ke Firestore collection 'users' dengan field:
      
uid, name, nim, email, createdAt, photoUrl, role
    
4. Update display name dengan credential.user!.updateDisplayName()
    
5. Simpan status login ke SharedPreferences
    
6. Tampilkan pesan sukses dan navigasi ke HomeScreen

Langkah 6: Uji fitur Upload Foto
    
1. Tekan menu "Upload Foto" di grid
    
2. Tekan area foto atau tombol "Kamera"/"Galeri"
    
3. Pilih foto → foto preview muncul
    
4. Tambahkan deskripsi (opsional) → tekan "Upload Foto"
    
5. Progress bar muncul selama upload
    
6. Snackbar hijau "Foto berhasil diupload!" muncul jika sukses
Langkah 7: Uji fitur Upload KTP
    
1. Tekan menu "Upload KTP"
    
2. Tekan area kartu KTP → pilih sumber (Kamera/Galeri)
    
3. Izinkan akses kamera jika diminta
    
4. Tekan "Upload KTP"
    
5. Verifikasi: data tersimpan di Supabase Storage (path ktp/{uid}/ktp.jpg) dan di Firestore collection 'ktp'
Langkah 8: Uji fitur Upload KTM
    
Langkah sama dengan Upload KTP. Perhatikan:
    
Badge status "Menunggu Verifikasi" (oranye) muncul setelah upload
    
Data tersimpan di path ktm/{uid}/ktm.jpg
    
Firestore collection 'ktm' berisi field status: 'pending'
Langkah 9: Uji fitur Logout
    
1. Di HomeScreen, tekan ikon ⋮ (titik tiga) di kanan atas
    
2. Pilih "Keluar"
    
3. Konfirmasi dialog → aplikasi kembali ke LoginScreen
    
4. SharedPreferences otomatis dihapus

Kesimpulan
Berdasarkan praktikum yang telah dilakukan, tampilan login sederhana berhasil dibuat dan dijalankan menggunakan Flutter. Aplikasi terdiri dari kolom Username, kolom Password yang karakternya disamarkan dengan obscureText, dan tombol Login yang dibuat dengan ElevatedButton. Tampilan tersebut tersusun dari widget MaterialApp, Scaffold, Center, Padding, Column, dan SizedBox.
Praktikum ini juga memberikan pemahaman tentang cara membuat project melalui Command Palette pada Visual Studio Code, struktur dasar aplikasi Flutter, serta cara menjalankan aplikasi dengan perintah flutter run pada browser Chrome.
Logika autentikasi pada tombol Login masih berupa kerangka (komentar pada onPressed) sehingga belum memverifikasi data pengguna. Pengembangan selanjutnya dapat dilakukan dengan menambahkan TextEditingController, validasi input, dan koneksi ke backend. Halaman login ini juga dapat dihubungkan dengan rancangan halaman Unggah Dokumen dan beranda My Campus Hub, sehingga membentuk alur aplikasi yang utuh mulai dari login hingga penggunaan fitur utama.
